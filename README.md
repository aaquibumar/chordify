# Chordify 🎸

Chordify is a clean, minimalist web application built for guitarists. It features an interactive song library, real-time chord transposition, interactive SVG chord fingering diagrams, and a built-in microphone guitar tuner.

## Features
- **Song Catalog & Reader:** Browse popular songs with chords, capo info, and strumming patterns.
- **Chord Transposer:** Instantly transpose chords up or down by semitones.
- **Interactive Chord Diagrams:** Click on any chord tag to view a fretboard fingering chart.
- **Guitar Tuner:** Real-time Web Audio API pitch detection with standard tuning presets ($E_2, A_2, D_3, G_3, B_3, E_4$).
- **Fully Responsive:** Minimalist Tailwind CSS design optimized for mobile and desktop.

## Hosting on GitHub Pages
1. Create a public repository on GitHub.
2. Upload `index.html` and `README.md`.
3. Go to **Settings > Pages**, select the `main` branch, and save. Your site will be live instantly!
