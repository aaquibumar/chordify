# Chordify 🎸

**Chordify** is a sleek, ultra-minimalist web application designed for guitarists, musicians, and song learners. It provides a distraction-free environment to view song chords, transpose keys on the fly, learn fretboard fingerings, and tune your guitar directly in your browser.

---

## ✨ Features

* **Song Catalog & Reader:** Browse a curated collection of popular songs complete with capo placement recommendations and strumming pattern guides.
* **Live Chord Transposition:** Instantly shift all chords up or down by semitones to match your vocal range or preferred key.
* **Interactive Fretboard Diagrams:** Click on any chord tag within a song to instantly pop up a visual SVG finger placement guide.
* **Built-In Guitar Tuner:** Real-time microphone audio pitch detection utilizing the Web Audio API with standard tuning presets ($E_2, A_2, D_3, G_3, B_3, E_4$) and a live needle meter.
* **Minimalist Design:** Built with clean typography, responsive layouts, and modern styling via Tailwind CSS.
